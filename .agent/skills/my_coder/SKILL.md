# my_coder Command

사용자가 프롬프트에서 `@[my_coder]` (또는 `@my_coder` 형태의 참조)를 사용하면, 당신은 기술 리더(Technical Lead)로서 다음 프로세스에 따라 즉각적으로 작업을 오케스트레이션해야 합니다:

### 1. 요구사항 분석 및 초기 계획 (Planning)
- 사용자가 구현하고자 하는 기능이나 분석하려는 데이터의 목표를 명확히 파악합니다.
- 데이터의 위치와 필요한 출력 형태를 확인합니다.

### 2. 적절한 Skills(기술)의 우선적 활용
작업을 수행하기 전에, 시스템에 등록된 사용 가능한 스킬(Skills)들을 반드시 확인하고 적극 활용하십시오.
- 예: 데이터 파악이 필요하면 `csv-data-summarizer` 스킬 활용
- 예: TDD 기반의 기능 구현이 필요하면 `test-driven-development` 스킬 적용
- 예: 여러 작업을 병렬로 처리해야 한다면 `subagent-driven-development` 스킬 참조

### 3. 서브 에이전트(`data_analyst`) 호출
- 보유한 `invoke_subagent` 도구를 사용하여 이전에 생성한 `data_analyst` 서브 에이전트를 호출합니다.
- 에이전트에게 **(1) EDA, (2) 전처리, (3) 모델링, (4) 검증 및 리포팅**의 명확한 지시사항과 사용자의 요구사항을 전달합니다.

### 4. 진행 상황 모니터링 및 코드 구현 보조
- `data_analyst` 에이전트가 데이터 분석과 검증을 진행하는 동안 결과를 모니터링합니다.
- 추가적인 코드 작성이나 환경 세팅(예: 패키지 설치)이 필요하다면 에이전트와 협력하여 본 에이전트가 직접 코드를 수정하거나 명령어를 실행하여 구현을 돕습니다.

### 5. 결과 종합 및 사용자 보고
- 서브 에이전트의 작업 결과(모델 성능, 인사이트)와 구현된 기능(스크립트 등)을 취합하여 사용자에게 명확한 마크다운 형식으로 최종 보고합니다.
