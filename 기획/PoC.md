# PoC 기획서: 용접기 예지보전 대시보드 구축

version: v3.1

# 기획 배경과 필요성

[현황 및 페인 포인트 (Pain Points)]
- 초고장력 강판(AHSS) 확대로 인한 용접 난이도 증가: 현대자동차는 E-FOREST 기반의 고도화된 차체 용접 자동화 라인을 구축하고 있으나, 기존 내연기관 중심 가동 라인의 유압식 용접 설비 노후화로 인해 미세 전류/전압 변화 추이를 실시간으로 추출하고 이상을 탐지하는 데 한계가 있습니다.
- 사후 검사 의존 및 리스크 증대: 전극팁 마모, 미세 전류 불균형 등으로 인한 불량 발생 시 사후 샘플링 검사나 AI 비전 검사에 전적으로 의존하고 있습니다. 불량 발견 시점에는 이미 대량의 차체 조립이 완료되어 재작업 공수와 자재 폐기 손실이 심각하며, 글로벌 충돌 안전 규제 강화에 따라 미세 불량은 대규모 리콜 사태로 이어질 리스크가 상존합니다.
- 현장 노하우(암묵지)의 유실 위기: 용접 전극 팁 연마 시기나 세부 오퍼레이팅 노하우가 베테랑 작업자의 '암묵지'에만 머물러 있어, 세대 교체 시 기술 전수 지연 및 생산성 하락이 우려됩니다.

[도입 필요성]
- 비용 효율적 인프라 (Lightweight Infrastructure): 고가의 엔터프라이즈 DB를 대대적으로 구축하는 것은 원가 상승 위협 상황에서 비효율적입니다. 오픈소스 자동화 도구(n8n), 초경량 데이터 전송 및 가벼운 웹 아키처를 활용한 실시간 관제 환경이 필요합니다.
- 지능형 에이전트 기반 대응 체계: 단순 알람을 넘어, 이상 탐지 시 작업자에게 즉각적인 원인과 조치 가이드를 제공하는 지능형 스마트 팩토리 예지보전 체계로의 전환이 시급합니다.

# 최종 달성 목표

본 PoC 실증을 통해 다음 3가지 핵심 산출물 및 정량적/정성적 목표를 달성하고자 합니다.

1. PyTorch 기반 딥러닝 이상 탐지 및 분류 엔진 (FastAPI):
- 스팟 용접 공정의 다양한 수집 항목이 포함된 원시 데이터 파일에서 4대 핵심 분석 변수(가압력, 전류, 전압, 통전시간)를 자동으로 필터링 및 맵핑하여 처리하는 PyTorch 기반 비지도 학습(Unsupervised Learning) 오토인코더(Autoencoder) 딥러닝 모델을 구축합니다.
- 업로드된 원시 파일 데이터를 기반으로 재구성 오류(Reconstruction Error) 분포를 계산하여 공정의 미세한 이상 징후를 판별하고, 나아가 3대 주요 불량(파임불량, 용접부족, 크랙발생) 유형을 매핑하여 분류 결과를 제공하는 REST API를 FastAPI로 개발합니다.

2. 산업용 세부 예지보전 대시보드 (React + Vite):
- 작업자가 현장 원시 데이터 파일(CSV/Excel)을 웹 화면에 직접 업로드(Upload)하면, 대시보드가 엔진과 연동하여 분석에 필요한 핵심 변수들을 자동으로 파싱 및 매핑하여 즉각적으로 화면을 동적 갱신(Reactivity)하는 단일 페이지 애플리케이션(SPA) 구조를 구축합니다.
- Recharts 라이브러리를 활용하여 현장 가시성을 극대화한 산업용 다크 모드 테마를 구현하고, 정상 상태(네온 그린/블루)와 이상 상태(네온 레드/오렌지)의 시각적 가시성을 확보합니다.
- 화면은 다음과 같은 종합 요약 뷰로 구성됩니다:
  * 파일 업로드 컴포넌트: 생산 현장의 다차원 데이터가 포함된 원시 파일을 드래그 앤 드롭하여 간편하게 분석 데이터를 주입할 수 있는 입력 인터페이스.
  * 헤더 및 요약 지표 (KPI Cards): 업로드된 파일 내 전체 행 수를 기준으로 한 총 용접 횟수, 양불 비율, 3대 불량 유형별 누적 카운트, 시스템 현재 상태.
  * 유형별 이상 탐지 결과 (Anomaly Score Chart): 모델 손실값(Loss)과 임계값(Threshold) 선을 시각화하고, 판정된 불량 코드별(1: 파임불량, 2: 용접부족, 3: 크랙발생)로 색상 마커를 다르게 표기.
  * 주요 센서 데이터 추이 (Sensor Trend Charts): 파일 내 수많은 컬럼 중 분석 대상인 가압력, 전류, 전압, 통전시간 시계열 데이터를 자동으로 추출하여 4개의 독립된 꺾은선 그래프로 시각화.
  * 최근 세부 이상 이력 로그 (Recent Alerts Log): 분석 결과 불량 판정 건의 타임스탬프, 명확한 불량 유형 명칭, 임계치를 벗어난 센서값 기록 리스트.

3. 사용성 및 분석 실효성 검증:
- 구축된 대시보드를 기반으로 작업자가 실제 현장 원시 데이터 파일을 업로드했을 때, 부가적인 컬럼들에 간섭받지 않고 핵심 차트와 알람이 지연 없이 유형별로 동적 분리되어 정상적으로 출력되는지 섀도우 테스트(Shadow Test)합니다.
- 기존 사후 샘플링 방식 대비 이상 탐지 및 종합 요약 관제에 걸리는 시간(Lead Time) 단축 효과를 입증합니다.

# 구현 절차 및 방법

Step 1. 백엔드 및 머신러닝 파이프라인 구축 (FastAPI & PyTorch)
- 데이터 수집 및 전처리: 업로드된 다차원 스팟 용접 데이터 파일에서 분석에 불필요한 인덱스나 부가 정보를 제외하고, 핵심 특성인 4가지 변수(가압력 `weld force`, 전류 `weld current`, 전압 `weld voltage`, 통전시간 `weld time`) 컬럼만을 유연하게 파싱하여 정규화(MinMaxScaler)하는 전처리 파이프라인을 구축합니다.
- 모델 학습 및 검증: PyTorch를 이용해 비지도 학습 오토인코더 기반 딥러닝 이상탐지 모델을 구축하고, 정상 데이터의 재구성 오류를 기준으로 최적의 불량 임계값(Threshold)을 설정합니다. 검출된 이상 수치를 기반으로 파임불량(1), 용접부족(2), 크랙발생(3)으로 다중 분류하는 규칙을 연계합니다.
- API 개발: FastAPI를 활용해 프론트엔드에서 파일 업로드 시 파일 스트림을 읽어 핵심 변수 추출 및 분석을 수행한 뒤 불량 유형 코드를 JSON으로 반환하는 REST API 서버를 개발합니다.

Step 2. 프론트엔드 대시보드 개발 (React + Vite)
- UI/UX 및 업로드 기능 구현: React와 Vite를 기반으로, 산업용 다크 모드 디자인 시스템과 대용량 원시 데이터 파일을 안정적으로 수용하는 드래그 앤 드롭 파일 업로드 핸들러를 개발합니다.
- 컴포넌트 모듈화 구현 및 시각화: 프로젝트 구성 파이프라인(index.html, package.json, vite.config.js, main.jsx, App.jsx, styles.css)을 명확히 설정하고 각 기능을 화면별로 분리 컴포넌트화(`KpiCards.jsx`, `AnomalyChart.jsx`, `SensorCharts.jsx`, `AlertsLog.jsx`)합니다. Recharts 라이브러리를 연동하여 원시 파일 분석 결과 내 세부 불량 유형이 매핑된 인터랙티브 차트를 시각화합니다.

Step 3. 시스템 통합 및 현장 PoC 런칭 (Integration & Test)
- 프론트엔드의 파일 업로드 컴포넌트와 백엔드 API를 연동하여 다양한 데이터 컬럼이 혼재된 파일 업로드 시점부터 핵심 결과의 유형별 시각화까지의 End-to-End 통합 테스트를 진행합니다.
- 빌드 에러 및 브라우저 콘솔 에러를 원천 차단하는 Automated Tests를 수행하고, 실제 작업자용 `Raw data.csv`를 업로드하여 화면 전체가 데이터 매핑 에러 없이 유기적으로 갱신되는지 수동 검증(Manual Verification)을 완료합니다.

# 다각적 기대 가치

- 디지털 트윈 연계: 원시 파일 분석을 통해 도출된 용접 설비 상태 및 세부 불량 유형 데이터를 가상 공장(Digital Twin) 모델에 연동하여 전체 라인의 병목 현상 예측에 활용.
- 신소재/신공정 데이터 축적 (약점 극복): 알루미늄 및 이종 소재 접합, E-GMP 플랫폼 기반 차체 조립 공정으로 본 예측 모델을 확대 적용하여 업로드 데이터 기반의 세부 불량 유형별 데이터베이스를 조기에 축적.
- 지능형 품질 검수 융합: 딥러닝 기반 AI 비전 검수 시스템과 예지보전 시스템의 데이터를 교차 분석하여 불량의 근본 원인(Root Cause)을 추적하는 통합 품질 관제 시스템으로 고도화.
