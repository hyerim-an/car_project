# 제품 요구사항 문서 (PRD)

- **프로젝트 명**: 현대자동차 용접기 지능형 예지보전 대시보드 구축
- **작성정보**: 
  - 작성자: [작성자명 입력]
  - 승인자: [승인자명 입력]
  - 작성일: 2026-06-01 v1.0
- **목적**:
  자동차 부품(Spot 용접) 공정에서 발생하는 품질 문제(용접 파임, 들뜸, 크랙 등)를 해결하기 위해, PLC-MES에서 수집되는 센서 데이터(가압력, 전류, 전압, 통전시간)를 실시간으로 모니터링하고, 오토인코더(AutoEncoder) 기반의 이상 탐지 AI 모델 결과를 연동하여 불량 발생을 사전에 예측하고 시각화하는 지능형 대시보드를 구축한다.
- **예상 소요일정**: 총 8주 (개발 및 QA 5주 포함)

## 대상 사용자 및 시장

### 1. 대상 사용자 정의
- **주요 대상 (Primary Target)**: 
  - 현대자동차 부품(용접) 공정 현장 작업자 및 설비 관리자 (가압력, 전류 등 공정 조건을 조정하는 실무자)
  - 행동 특성: 여러 설비의 상태를 동시에 모니터링하며, 직관적인 시각적 알람에 민감하게 반응해야 함.
- **보조 대상 (Secondary Target)**:
  - 품질 관리 부서 및 생산 기술팀 (불량 원인 분석, AI 모델 성능 및 임계값 튜닝 담당)

### 2. 시장 규모 및 성장성
- **TAM**: 글로벌 제조 AI 및 예지보전 솔루션 시장 규모 약 $USD 25B$
- **SAM**: 국내 자동차 부품 제조 및 품질 관리 AI 솔루션 시장 약 $USD 1.5B$
- **SOM**: 현대자동차 계열사 및 1차 협력사 Spot 용접 라인 예지보전 구독 시장 (출시 2년 내 점유율 10% 목표)

### 3. 경쟁 제품 분석 및 차별화
- **경쟁사 (기존 통계 기반 모니터링 화면)**:
  - 강점: 기존 현장 설비(PLC)와의 강력한 레거시 연동
  - 약점: 통계적 분석 위주로, 비지도 학습(AutoEncoder) 기반의 고도화된 이상 탐지와 센서 간 복합적 상관관계를 보여주는 기능 부족
- **우선 순위 경쟁 우위 전략 (The Predictive Edge)**:
  - 오토인코더 모델 결과(Reconstruction Error)를 이용한 실시간 Anomaly Score 시각화
  - 주요 4대 변수(weld force, current, voltage, time)의 분포와 추이를 산업용 다크모드 기반의 고가시성 대시보드로 실시간 제공

### 4. 페르소나 및 User Story
- **페르소나 1 (설비 관리자 최현대)**: 
  - 일상 패턴: 로봇 기반이 아닌 수작업 기반의 Spot 용접 라인 관리. 기존엔 육안 검사에 의존하여 피로도가 높음.
  - 핵심 페인포인트: 공정 조건 최적화가 직관과 경험에만 의존됨.
  - 성공 시나리오: 대시보드의 실시간 경고를 보고 불량 발생 전 선제적으로 전극이나 가압력을 조절함.
- **User Story**:
  - [User Story 1] As a 현장 작업자, I want 실시간으로 내 용접기의 4대 센서 변수 추이를 한 화면에서 보고 싶다, so that 용접 품질이 떨어지기 전에 즉각적인 조치를 취할 수 있도록.
  - [User Story 2] As a 품질 관리자, I want 오토인코더 모델의 Loss 분포와 임계값 기준을 시각적으로 확인하고 싶다, so that AI 모델의 불량 예측 정확도를 평가하고 튜닝할 수 있도록.
  - [User Story 3] As a 공장장, I want 일별 양품/불량품 개수 및 가동 상태 요약(KPI)을 보고 싶다, so that 전체 공정의 수율(Yield Rate) 개선 효과를 파악할 수 있도록.

## 주요 기능

- [MVP / P0] **Master Sensor Data Streamer (실시간 센서 데이터 연동 및 전처리)**
  - What: PLC-MES 및 MongoDB에 적재되는 8초 주기의 센서 데이터를 실시간 스트리밍
  - Why: 실시간 모니터링을 위해 필수
  - How: 웹소켓을 통한 데이터 수신. 결측치 및 이상값 노이즈 필터링 (MinMaxScaler 정규화)
  - Success Criteria: 데이터 지연율 $3.0s$ 이하
- [MVP / P0] **AI Anomaly Detection Visualizer (오토인코더 이상 탐지 시각화)**
  - What: 텐서플로우/파이토치로 학습된 AutoEncoder 모델의 예측 손실값(Reconstruction Error)과 임계값(Threshold)을 실시간 차트로 표현
  - Why: 불량 예측을 직관적으로 알림
  - How: Loss 값을 실시간 꺾은선으로 그리고, Threshold 선을 초과 시 붉은색 알림 점멸 (산업용 다크모드 테마 적용)
  - Success Criteria: 불량 탐지 결과 시각화 오차 $0$
- [MVP / P0] **4-Factor Correlation Dashboard (4대 변수 종합 요약 뷰)**
  - What: 용접 가압력, 전류, 전압, 통전 시간의 추이와 히스토그램을 한 화면에 배치
  - Why: 이상 발생 시 어느 변수가 원인인지 즉시 파악
  - How: React + Vite 및 Recharts를 활용하여 반응형 대시보드 컴포넌트로 구현
  - Success Criteria: 컴포넌트 렌더링 60FPS 유지
- [Phase 2 / P1] **Historical Analysis & Threshold Tuning (과거 데이터 분석 및 임계값 튜닝 뷰)**
  - What: 특정 기간의 데이터(scaled_data.csv 등)를 불러와 상관관계 히트맵을 그리고, 관리자가 임계값을 수동 조절해보는 시뮬레이터
  - Why: 비지도 학습 특성상 목표치(label) 부재를 보완하고 모델을 고도화하기 위함
  - How: 대시보드 내 설정 패널을 통해 Threshold 변수 조정 시 UI 리렌더링
  - Success Criteria: 튜닝에 따른 UI 반영 소요시간 $1.2s$ 이하

## 기술 요구사항

### 1. 인프라 및 핵심 파이프라인
- 데이터 수집: MongoDB 및 PLC-MES Data 연동
- AI 파이프라인: Python 백엔드 연동, Scikit-learn (MinMaxScaler 전처리) 및 PyTorch 서빙

### 2. 프론트엔드 아키텍처 및 렌더링
- 프레임워크: React + Vite (SPA 환경)
- 스타일링: 산업용 다크 모드 (Industrial Dark Mode) CSS 테마
- 시각화: 빠르고 동적인 데이터 표시를 위해 Recharts 또는 Chart.js 채택

### 3. Database
- 시계열 센서 데이터 관리에 특화된 백엔드 DB 연동 구조 확립

   - 지표: 일일 공정 관리자의 대시보드 체류 시간 및 상호작용 횟수

## Out of Scope (개발 제외 범위)

1. **용접기 직접 제어 (설비 제어 자동화)**
   - 제외 사유: 오판 시 설비 파손 및 안전 사고의 위험이 크므로 본 단계에서는 모니터링 및 알람에만 집중.
   - 대안: 현장 작업자가 대시보드 확인 후 수동으로 조치하도록 가이드라인 제공.
2. **영상 기반 불량 탐지 (비전 AI)**
   - 제외 사유: 현재 제공된 데이터셋이 시계열 수치 데이터(csv) 기반이므로 비전 AI 도입은 범위를 벗어남.
   - 대안: 차기 페이즈(Phase 3)에서 영상 데이터 수집 환경이 구축되면 도입 검토.

## 개발 일정 및 로드맵
- **1단계 (1~2주차)**: React + Vite 프로젝트 세팅, 다크모드 UI/UX 설계 및 데이터 수집 파이프라인 구축.
- **2단계 (3~4주차)**: AI 모델(AutoEncoder) 서빙 API 개발 및 프론트엔드 실시간 연동.
- **3단계 (5~6주차)**: 실시간 센서 차트 및 이상 탐지 시각화 컴포넌트(종합 요약 뷰) 완성.
- **4단계 (7~8주차)**: 과거 데이터 튜닝 뷰 개발, 통합 테스트 및 현장 적용.

## 리스크 및 의존성
- **데이터 품질 저하 리스크**: 
  - 리스크: 수집된 센서 데이터에 Null 값이나 노이즈가 과다할 경우 AI 예측 성능이 급감.
  - 완화 방안: 완전성, 유효성을 지속 검사하는 데이터 전처리 파이프라인 강제 적용.
- **레이블(Label) 부재 한계**:
  - 리스크: 개별 용접 건에 대한 명확한 양/불 레이블이 없어 모델의 정량적 평가가 힘듦.
  - 완화 방안: 일별 불량품 총 개수와 예측 개수의 추이를 비교하는 정성적/통계적 검증 방식을 통해 지속 모니터링 체계 도입.
