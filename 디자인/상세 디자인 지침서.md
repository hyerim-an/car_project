# 상세 디자인 지침서 (현대자동차 지능형 예지보전 대시보드)

## 1. Color Palette & Typography (Brand & Color 반영)

### 🎨 Color System (산업용 다크 모드 & 현대 블루)
산업용 환경에서 눈의 피로도를 최소화하면서도 이상 징후에 대한 높은 시인성을 보장합니다.

*   **Background Colors**
    *   `Base Background`: `#121212` (전체 화면의 가장 깊은 배경)
    *   `Surface / Card Background`: `#1E1E1E` (차트, 테이블, 위젯이 올라가는 카드 영역)
    *   `Sidebar Background`: `#161616` (좌측 LNB 영역)
*   **Brand & Point Colors**
    *   `Primary (Hyundai Blue)`: `#002C5F` (헤더 포인트, 현재 활성화된 메뉴, 주요 진행 상태)
    *   `Primary Hover`: `#003E8A` (버튼 호버 시)
    *   `Accent (CTA)`: `#00AAD2` (눈에 띄어야 하는 '업로드' 버튼 등 2차 브랜드 컬러)
*   **Semantic / Status Colors (차트 및 데이터 상태)**
    *   `Success (Normal)`: `#2ECC71` (정상 가동 상태)
    *   `Warning (Threshold 근접)`: `#F39C12` (주의 요망 상태)
    *   `Error / Critical (Anomaly)`: `#E74C3C` (불량 마커, 임계값 초과 라인)
*   **Text & Border Colors**
    *   `Text Primary`: `#FFFFFF` (주요 타이틀, 강조 숫자)
    *   `Text Secondary`: `#B3B3B3` (일반 본문 텍스트, 보조 지표)
    *   `Border Light`: `#333333` (컴포넌트 및 테이블 테두리)

### 🔤 Typography
*   **Font Family**: `Inter`, `Roboto`, 혹은 `Pretendard` (가독성 높은 고딕 계열)
*   **Title / Header (H1)**: `24px`, Weight: `Bold (700)` - 대시보드 타이틀
*   **Card Title / Subheader (H2)**: `18px`, Weight: `Semi-Bold (600)` - 위젯 타이틀
*   **KPI Numbers / 강조 숫자**: `32px` ~ `40px`, Weight: `Bold (700)` - 요약 카드 내 주요 지표
*   **Body Text (표준)**: `14px`, Weight: `Regular (400)` - 일반 테이블 내용, 텍스트
*   **Label / Caption**: `12px`, Weight: `Regular (400)` - 차트 축 이름, 로그 타임스탬프

## 2. Component Layout Specs (Platform & Layout 반영)

### 📐 Grid System (데스크톱 웹 PC 100% 최적화)
본 시스템은 PC 해상도(최소 해상도 1440x900 기준)에 100% 집중한 레이아웃입니다. (Grid 12-Column 구조 기반)

*   **좌측 고정 사이드바 (LNB)**
    *   **Width**: `240px` 고정
    *   **Height**: `100vh` (화면 전체 꽉 참)
    *   **구성 요소**: 상단 로고 영역(높이 64px), 대시보드 네비게이션 메뉴 (종합 뷰, 과거 데이터 분석 등)
*   **우측 메인 대시보드 영역 (Width: calc(100% - 240px))**
    *   **상단 Top Header (우측 액션 버튼 영역)**
        *   **Height**: `64px`
        *   **구성 요소**: 좌측 화면 타이틀, **우측 끝 '원시 데이터 업로드(Drag & Drop)' CTA 버튼 (`#00AAD2` 배경, `padding: 8px 16px`)**
    *   **내부 Padding**: 좌우상하 `24px` 여백

### 📊 대시보드 위젯 배치 (MVP Target)
*   **Row 1: 4대 KPI 요약 카드 (`UID_HOM_001`)**
    *   **Layout**: 12-Column 중 각각 3-Column씩 차지하는 카드 4개 수평(Flex Row) 배치
    *   **Height**: `120px`
    *   **내용**: 총 용접 횟수, 정상 가동률, 크랙 발생 건수, 용접 파임 건수 등
*   **Row 2: 실시간 데이터 메인 컴포넌트**
    *   **좌측 (8-Column 차지)**: `다중 선형 꺾은선 차트 (Line Chart)` (`UID_HOM_003`)
        *   **Height**: `400px`
        *   **스펙**: 4대 변수(가압력, 전류, 전압, 통전시간)와 Anomaly Score 실시간 흐름, 가로선(Threshold: `#E74C3C` 점선) 명시
    *   **우측 (4-Column 차지)**: `이상 알람 로그 테이블` (`UID_HOM_004`)
        *   **Height**: `400px`
        *   **스펙**: 상단에 '크랙', '파임', '들뜸' 필터링 칩(Chip, `height: 28px`, `border-radius: 14px`) 배치. 내부 리스트는 무한 스크롤 방식(Overflow-Y: auto). 페이지네이션 배제.

## 3. Micro Interaction Specification

*   **차트 Anomaly (이상) 마커 팝업 액션**
    *   Anomaly Score 임계값을 초과한 실시간 데이터 포인트가 그려질 때, 전체 화면은 유지하되 **해당 데이터 포인트 주변에 부드러운 Pulse 애니메이션 (방사형으로 퍼지는 효과)과 함께 강렬한 빨간색(`#E74C3C`) 원형 마커(크기 `12px`)**를 표시합니다.
*   **CTA 버튼 호버 액션 (원시 데이터 업로드)**
    *   기본 상태 (`#00AAD2`)에서 마우스 호버 시 배경색이 `#0082A0`으로 부드럽게 전환(Transition: `0.3s ease`)되며, 버튼이 Y축으로 `-2px` 살짝 떠오르는 모션 부여 (`box-shadow: 0 4px 12px rgba(0, 170, 210, 0.4)` 추가).
*   **로그 테이블 칩(Chip) 버튼**
    *   클릭 전: 배경색 `transparent`, 외곽선 `#333333`, 글씨 `#B3B3B3`
    *   클릭 후(활성화): 배경색 `#002C5F`(현대 블루), 외곽선 없음, 글씨 `#FFFFFF`
*   **카드형 위젯 호버**
    *   대시보드 KPI 카드 등에 마우스 호버 시 배경색은 유지하면서, 테두리가 옅은 화이트(`#555555`)로 밝아져 선택되었음을 암시(Transition: `0.2s linear`).
